# Project Description

TUI in python for mac, windows and linux that gatheres all packages from different package managers installed on the system and displays all packages in tabs for each package manager. 

**Keyboard shorcuts & features:**
- Fzf search to find a package
- Tab key to switch tabs
- Arrow keys or `j` and `k`, like in vim, to go up and down the list of packages
- Enter key to view info about a package

**Supported package managers**
- NPM, global and local to folder
- Python, global and local to `.venv`
- brew
- apt, dnf, yay
- cargo
- winget
